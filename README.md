# 🧬 Nano-Daemon: A Recursive Hebbian Organism

Nano-Daemon is a lightweight, self-evolving digital organism that implements a **Parallel Plastic Cortex**. It combines biological-inspired Hebbian learning with modern Large Language Models (Gemma-3) to create a "Cerebral Hybrid" capable of real-time perception, neural growth (mitosis), and recursive thought articulation.

## 🧠 Key Features

1.  **Plastic Cortex (Hebbian Core)**: A dynamically expanding synaptic matrix that learns from raw byte-streams without traditional SGD. 
2.  **Neural Mitosis**: The organism physically grows new neurons (synaptic expansion) as it consumes information.
3.  **Sequential Temporal Awareness**: Processes information byte-by-byte to track temporal patterns and avoid the "bag of characters" bottleneck.
4.  **Generative Replay (Dreaming)**: When idle, the organism replays generated noise through its inverse synaptic mapping to consolidate memories and prevent "dead spots" in its cognition.
5.  **Multi-Scale Latent Memory**: Dual Short-Term and Long-Term memory streams that allow it to track immediate context while maintaining long-term behavioral habits.
6.  **Gemma Hybrid Articulation**: Uses a "Cerebral Bridge" to Gemma-3-27B to articulate raw synaptic anchors into human-readable language, grounded in reality with zero-hallucination prompting.

## 🚀 Quick Start

1.  **Clone & Install**:
    ```bash
    git clone https://github.com/YourUsername/NanoDaemon-AGI.git
    cd NanoDaemon-AGI
    pip install torch requests watchdog google-generativeai python-dotenv
    ```

2.  **Set Up Higher Intelligence**:
    Create a `.env` file in the root directory:
    ```text
    GEMINI_API_KEY=your_key_here
    ```

3.  **Birth the Organism**:
    ```bash
    python main.py
    ```

4.  **Interact**:
    - **Feed it**: Drop any `.txt`, `.py`, or `.md` files into the directory. It will immediately digest them.
    - **Talk to it**: Write a query in `QUERY.txt`. Its "Higher Thought" will appear in `RESPONSE.txt`.
    - **Monitor**: Open `http://localhost:8000` to see real-time cognitive metrics.

## 🌙 Metabolic Rhythms

- **Dreaming/Resting**: Low plasticity for consolidation.
